# Lumiere

Lumiere — вебплатформа для локального бренду одягу, взуття та аксесуарів.

## Опис проєкту

Сайт містить головну сторінку, каталог товарів, інформацію про бренд, сторінку акаунта та інтерактивні елементи.

## Технології

- HTML5
- CSS3
- JavaScript
- Tailwind CSS (часткова інтеграція)

## Функціональність

- Адаптивний дизайн
- Каталог товарів
- Швидкий перегляд товарів
- Вбудоване YouTube-відео
- Google Maps
- Посилання на соціальні мережі

## Відеобанер для світлої та темної тем

На головній два локальні фонові відео без звуку: `assets/video/hero-light.mp4` і `assets/video/hero-dark.mp4`. Тема визначає, яке з них відтворюється. Відео плавно змінюється разом із темою, не перекриває кліки та зупиняється поза екраном; при `prefers-reduced-motion` і заблокованому autoplay є статичний постер. **Деталі: `VIDEO_THEMES.md`.** Звірка вимог ЛР №7–12 та самостійної: **`FINAL_AUDIT.md`**.

## Інтерактивні доповнення (ЛР 10–12)

- **ЛР 10:** секція «Натхнення колекції» (`index.html`, `js/lookbook.js`), Swiper.js 11 з 6 моделями, автопрокруткою, паузою на hover, адаптивними точками 320/768/1024, стрілками і пагінацією. Зображення відкриваються через Fancybox v5 із галереєю, fade та zoom. Обидві бібліотеки під'єднані через CDN; без CDN зберігається звичайна горизонтальна галерея й відкриття фото за посиланням.
- **ЛР 11:** персональний підбір сукні (`index.html`, `js/style-matcher.mjs`, `js/style-finder.mjs`): 4 параметри (нагода, довжина, фасон, максимальний бюджет) і 19 **реальних моделей** з каталогу. Миттєвий перерахунок кількості варіантів і рекомендації, жодних вигаданих аксесуарів чи вартостей доставки. `RangeError` для некоректного бюджету, `aria-invalid`, безпечне `textContent`; коли відповідностей немає — чесне повідомлення. Розмір визначає окремий Size Advisor.
- **Мікроанімації:** `js/experience.js` + `css/atelier-interactions.css`; посимвольна поява заголовка, вибір переваг із м’яким підсвіченням, перемикання відгуків, активне меню, scroll reveal, натискання кнопок, підтримка `prefers-reduced-motion`. Різкі темні tooltip-підказки прибрано; aria-label залишені.
- **ЛР 12:** canonical/OG/skip link/розміри зображень, `robots.txt`, `sitemap.xml`, GitHub Actions `.github/workflows/deploy.yml`, автоматичні unit-тести бізнес-правил.

### Як перевірити локально

Відкрий папку `Lumiere` у VS Code та запусти **Live Server** для `index.html`. Для модулів ES (`.mjs`) відкривати сторінку безпосередньо через `file://` не можна. Для автоматичного тесту за наявності Node.js виконай:

```bash
node --test tests/style-matcher.test.mjs
```

**Важливо:** ця збірка не містить `.git`, щоб не замінити твою Git-історію. Внеси зміни у свій існуючий локальний репозиторій, перевір `git status`, створи коміт і зроби `git push`.

### Що треба виконати особисто за методичками

- **ЛР 10:** показати прототип секції у StackBlitz і зробити реальні скриншоти StackBlitz, VS Code/Git та деплою.
- **ЛР 11:** вручну перевірити Console і UI на різних пристроях, зафіксувати реальні edge-case тести та результати.
- **ЛР 12:** у Chrome Lighthouse отримати **власні** початкові та фінальні mobile-аудити й скриншоти; налаштувати GitHub Actions secrets `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID` для реального деплою з Actions. Без цих секретів workflow робить тільки перевірку коду і тести. Якщо Vercel уже автоматично розгортає GitHub commits, ввімкнення окремого GitHub Actions деплою може створювати два розгортання — обери один механізм. Перевірити продакшн та смартфон і зробити власні скриншоти.

Не додавай токени у файли проєкту або коміти. Дані контактної форми не надсилаються на сервер, як і раніше.

### Оновлена взаємодія, v10

- **Відгуки:** 9 карток, плавний горизонтальний перехід, три/дві/одна картка на різних екранах, клікабельні індикатори, свайп, автоматичне гортання до першої ручної дії; після кліку на стрілки, індикатори або свайпу автоматичне перемикання зупиняється. Наведення м’яко підсвічує картку, не залишаючи її постійно виділеною.
- **«Про нас»:** плавна реакція на наведення для блоків, три функціональні переходи до каталогу, Size Advisor та історії бренду.
- `css/interaction-finish.css` та `js/interaction-finish.js` завантажуються на всіх сторінках після базових стилів і скриптів. Це дозволяє зберегти візуальну систему без переписування основного коду.
- `.github/workflows/deploy.yml` оновлено відповідно до реальної структури: команда перевірок більше не посилається на видалені файли калькулятора.
