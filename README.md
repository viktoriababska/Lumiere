# Lumiere

Lumiere — вебплатформа для локального бренду одягу, взуття та аксесуарів.

## Опис проєкту

Сайт містить головну сторінку, каталог товарів, інформацію про бренд, сторінку акаунта та інтерактивні елементи.

## Технології

- HTML5
- CSS3
- JavaScript
- Tailwind CSS (часткова інтеграція)

## Функціональність

- Адаптивний дизайн
- Каталог товарів
- Швидкий перегляд товарів
- Вбудоване YouTube-відео
- Google Maps
- Посилання на соціальні мережі
