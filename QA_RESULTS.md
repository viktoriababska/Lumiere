- **36/36** додаткових браузерних регресій: повне коло гортання всіх 9 відгуків на телефоні та 3 сторінок на комп’ютері, інтерактивні переходи «Про нас», швидкий перегляд, вибір розміру, додавання в кошик.
- **56/56** автоматичних Node.js тестів підбору сукні: не переплутує міні/максі, перевіряє бюджет та невалідні значення.
- **0** відсутніх локальних посилань на HTML/JS/CSS/зображення у базовій перевірці.

## Обмеження перевірки

Тести в контейнері проходили у Chromium з локально вбудованими CSS/JS і зображеннями, оскільки доступ до зовнішніх ресурсів був обмежений. Тому для ЛР №10 ще треба перевірити Swiper.js та Fancybox через CDN у власному Live Server, а для ЛР №12 — фактичний запуск GitHub Actions, публікацію на Netlify/Vercel, Lighthouse, роботу на справжньому смартфоні. Проєкт не публікувався й дані до GitHub не надсилалися.
