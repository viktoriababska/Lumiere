# Lumiere · Фінальне оновлення (23.11.2026)

Збережено наявний дизайн, структуру, всі 21 картку каталогу, кошик, модальні вікна,
Size Advisor, форму зворотного зв’язку, checkout-валидацію, Fancybox/Swiper,
фільтри, фаворити та іншу логіку попередніх лабораторних.

## Що змінено

1. **Головна: анімований заголовок** (`index.html`, `js/experience.js`,
   `css/atelier-interactions.css`). Поява символів по черзі, без зміни тексту.
   Для налаштування «Зменшення руху» анімація вимикається.

2. **Переваги: інтерактивні картки** (`index.html`, `js/experience.js`,
   `css/atelier-interactions.css`). Наведення або натискання на «Деталь» змінює
   підсвічення та пояснення; працює з клавіатури. Картки залишилися квадратними,
   іконки без білих підкладок, без різкого зсуву всієї сітки.

3. **Відгуки: м’яке перегортання** (`index.html`, `js/experience.js`,
   `css/atelier-interactions.css`). Стрілки, індикатори, автоматичний вибір
   активної картки, свайп на мобільному, пауза при наведенні, reduced-motion.
   Усі оригінальні три відгуки залишилися без змін.

4. **Швидкий перегляд** (`css/atelier-interactions.css`). Тепла напівпрозора
   кремова кнопка замість великої темної, м’який hover; зображення збережені без
   обрізання, відкриття модального вікна та вибір розміру збережені.

5. **ЛР №11: новий підбір сукні** (`index.html`, `js/style-matcher.mjs`,
   `js/style-finder.mjs`, `tests/style-matcher.test.mjs`). Заміна демонстраційного
   кошторису вигаданих аксесуарів на підбір РЕАЛЬНИХ товарів Lumiere з 4
   параметрів (нагода, довжина, фасон, бюджет). Автоматичне оновлення результату,
   фото та ціни товару, перехід до нього в каталозі, обробка Edge Cases.
   Не замінює Size Advisor та не проводить оплату.

6. **Про нас** (`about.html`, `css/atelier-interactions.css`). Контрастна кнопка
   на світлому тлі, делікатні реакції блоків, FAQ; прибрано різкі темні tooltip.

7. **Оновлення сторінки** (`<head>` HTML-сторінок). Встановлено
   `history.scrollRestoration = "manual"`; при reload без явного #якоря
   сторінка повертається на початок. Навмисні посилання на секції (#feedback)
   залишаються робочими.

## Що перевірено

- `node --test tests/style-matcher.test.mjs`: **27 / 27** пройшло.
- Локальний браузерний тест HTML/CSS/JS: **67 / 67** перевірок на 320,
  375, 768 і 1440 px, включно з відгуками, перевагами, UI-підбором,
  модальним переглядом, FAQ, відсутністю горизонтального прокручування.
- Перевірено 19 моделей суконь у модулі підбору; 2 комплекти в каталозі збережені.
- **Обмеження:** CDN-бібліотеки та реальне оновлення сторінки в браузері з
  локальним HTTP-сервером не вдалося перевірити через мережеві обмеження
  тестового середовища. Перевірте у VS Code → Live Server на своєму ПК.
