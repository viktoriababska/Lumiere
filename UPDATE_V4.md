# Lumiere — інтерфейс v4 (23.11.2026)

## Що виправлено

- **Ціни:** вирівняно заголовок і ціну в картках каталогу; ціна в «Швидкому перегляді» тепер знаходиться у блоці деталей, без абсолютного позиціонування.
- **Відгуки:** дев’ять **демонстраційних прикладів** замість трьох, гортання стрілками та крапками. По 3 картки на комп'ютері, 2 на планшеті, 1 на смартфоні. Автопрокручування призупиняється при взаємодії; за налаштуванням «Зменшити рух» автоматична зміна вимикається. Приклади позначені як демонстраційні, не як справжні підтверджені відгуки.
- **Помічник підбору:** за вибраними параметрами можна послідовно переглянути **всі** відповідні моделі. Лічильник 1 / N, стрілки вперед/назад. Тільки дійсні наявні моделі. Неправильний бюджет показує помилку.
- **«Про нас»:** плавніша анімація появи тексту; в FAQ одночасно відкритий лише один пункт, індикатор став м'якшим.
- **Іконки шапки:** кругле підсвічення без квадратних плашок, доступність для клавіатури.
- **Переваги:** прибрано дублюючі кнопки «Деталь» та додаткову плашку. Чотири картки з м’яким hover і наявними корисними посиланнями.
- **Акаунт:** спільна з іншими сторінками палітра, ширини, шрифти, полегшені блоки, покращена мобільна версія. Не приховано факт, що авторизація — демонстраційна.
- **Модальні вікна:** обробники переходів між кошиком, оформленням та вибором розміру не дублюють події.

## Основні файли

- `index.html` — відгуки, переваги, керування підбором.
- `about.html` — ексклюзивні блоки FAQ.
- `account.html` — актуалізований текст демо-акаунту.
- `css/atelier-interactions.css` — усі фінальні візуальні корекції.
- `js/experience.js` — відгуки, анімації, інтерактивність, FAQ.
- `js/style-finder.mjs` — гортання всіх збігів, пов’язане з `js/style-matcher.mjs`.
- `js/app.js` — безпечніші події у модальних вікнах.

## Перед публікацією

1. Розпакуй ZIP **в окрему папку** і відкрий `index.html` у VS Code з **Live Server**.
2. Переглянь головну, каталог, «Про нас», акаунт і оформлення замовлення на ПК й у мобільному режимі DevTools.
3. Перевір Swiper/Fancybox та зовнішні сервіси при **доступному інтернеті**: CDN-залежності в офлайновому тестовому середовищі не перевірено на реальному сервері.
4. Залиши резервну копію старого сайту. Перенеси файли в існуючий Git-проєкт **без видалення `.git`**, перевір `git status`, зроби commit і push.
5. Демонстраційні відгуки заміни перевіреними реальними, якщо сайт використовуватиметься не тільки для навчання. Демоформи не надсилають замовлення на сервер.
