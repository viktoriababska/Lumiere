# Lumiere — v8, корекція швидкого перегляду та структури ZIP

- «Швидкий перегляд» — справжня HTML-кнопка зі світлим теплим фоном, тонкою рамкою та делікатним hover. Вона розташована під фото, в інформаційному блоці картки.
- При натисканні відкриває попереднє модальне вікно; JS та логіка кошика не змінювалися. Усунуто конфлікт старих CSS hover-правил, через який натискання могло потрапляти повз кнопку.
- Загальний стиль суконь, решта анімацій і поведінка сторінок збережені.
- ZIP містить одну кореневу папку Lumiere; відкривати цю папку через VS Code, запускати index.html через Live Server.
- Зміни внесені у css/final-refinements.css.
