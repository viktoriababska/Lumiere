# Lumiere — інтерактивність і остаточне доопрацювання

## Удосконалення
- `css/interaction-finish.css` — узгоджені hover/focus/active стани: блоки «Про нас», картки переваг, відгуки, кнопки та медіасекції. Прибрано конфлікт зі старими `!important` CSS.
- `js/experience.js` — горизонтальна карусель дев’яти відгуків із групуванням по 1/2/3, стрілками, пагінацією, свайпом, автогортанням та справжньою кнопкою паузи.
- `js/interaction-finish.js` — м’яке підсвічення відгуків за рухом курсора.
- `index.html` — шкала автогортання відгуків.
- `about.html` — плавне підсвічення секції «Зрозумілий вибір», матеріалів, догляду та інших інформаційних блоків (без беззмістовних кліків).
- Збережено підбір суконь, модальні вікна, кошик, валідацію, семантику та адаптивну кнопку «Швидкий перегляд» поверх фото.

## Вимоги ЛР №10–12
- ЛР10: Swiper.js/Fancybox через CDN у секції lookbook, існуюча медіагалерея та анімації.
- ЛР11: підбір суконь на чотирьох параметрах, перевірки edge cases та тести.
- ЛР12: адаптивність, семантика, SEO-файли й GitHub Actions (локальний код).

Важливо: скриншоти StackBlitz і Chrome DevTools, фактичний запуск GitHub Actions, показники Lighthouse і тест на справжньому телефоні не можна підтвердити одним локальним ZIP. Виконай ці перевірки після деплою.

## Запуск
1. Розпакувати ZIP — всі файли в одній папці `Lumiere`.
2. Відкрити папку в VS Code та запустити `index.html` через Live Server.
3. Перевірити відгуки стрілками й свайпом, паузу, наведення на блоки «Про нас», каталог, кошик.
4. Для оновлення кешованих стилів натиснути Ctrl + Shift + R.

*Архівовані нотатки попередніх версій збережено в `docs/previous-updates/`.*
