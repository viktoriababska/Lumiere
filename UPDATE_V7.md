# Lumiere — v7, точкове візуальне доопрацювання

- **Швидкий перегляд:** текстове посилання під фото (без фону, рамки-кнопки, тіні чи плашки). Клік відкриває те саме модальне вікно; зображення також залишається клікабельним. Семантично це `<button>` для роботи клавіатурою, але візуально це лише підкреслений текст.
- **Наведення на сукні:** забрано підняття, масштабування фото й сильну тінь; лише дуже делікатний акцент рамки з плавною зміною.
- **Про нас:** при наведенні на блоки «Зрозумілий вибір», «Підказка з розміром» і «Український характер» більше немає різкого лівого бордера, зсуву й заливки. Залишено м’яку зміну кольору назви.
- **Без змін:** логіка швидкого перегляду, кошика, валідації, каталогу, відгуків, підбору сукні й інших лабораторних.

Оновлені файли: `index.html`, `catalog.html`, `css/final-refinements.css`.

Перевір перед деплоєм через Live Server (Ctrl+Shift+R для очищення кешованого CSS). Не замінюй папку `.git`.
