# Lumiere — світла і темна тема

Перемикач сонце/місяць у шапці кожної HTML-сторінки. Тема зберігається в localStorage (`lumiere-theme`), не скидається після перезавантаження або переходу.

- Світла тема залишилася базовою, фотографії та анімації не змінені.
- Темна головна: `assets/images/hero-dark.jpg` — надане користувачем фото.
- Темна «Про нас»: `assets/images/about-dark.jpg` — надане користувачем фото; банер у темній темі повноширинний, а у світлій зберігається попередня верстка.
- Стилі: `css/themes.css`; логіка й збереження: `js/theme.js`; встановлення теми до завантаження CSS: `#theme-prepaint` у `<head>`.
- Код кошика, оплати, валідації, підбору суконь, відгуків, Swiper, Fancybox не змінювалися.

Для перегляду відкрийте `Lumiere/index.html` через Live Server. У приватному режимі тема може не зберігатися (залежить від налаштувань браузера). Перед публікацією перевірте всі сторінки в обох темах, особливо сторонні iframe.
