# Lumiere — v9 · кнопка поверх фото (поліпшення естетики)

- На головній та в каталозі **кожна** картка сукні має `button.quick-view` **усередині** `.product-image-box`, а не під фото. Включно з 6 старими картками каталогу.
- На комп’ютері кнопка «Швидкий перегляд» м’яко з’являється над нижнім краєм фотографії (fade + slight rise), разом із дуже делікатною тінню, градієнтом та підсвіченням.
- На сенсорних екранах кнопка видима постійно: не потрібно намагатися «навести» курсор пальцем.
- Кнопка лишається справжнім `<button type="button" data-quickview="…">`, обробник події в `js/app.js` не змінено. Зберігаються модальне вікно, вибір розміру, кошик і обране.
- Для людей зі зменшеною анімацією (`prefers-reduced-motion`) переходи прибираються.
- Внесено зміни в `index.html`, `catalog.html` і новий файл `css/quickview-overlay.css`, завантажений останнім.
- **Решту сайту та вимоги лабораторних 10–12 не змінено:** секції зі сторонніми Vanilla JS бібліотеками через CDN, віджет підбору з тестами, форми й валідація, підключення GitHub Actions залишилися на своїх місцях.
- ZIP містить одну кореневу папку `Lumiere/`. Відкривай її через VS Code та запускай через Live Server.
